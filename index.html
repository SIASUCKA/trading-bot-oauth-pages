What this application is

Kylo's Trading Bot Alerts is a personal software tool, built and used by a single individual (the developer), that automates a paper-trading (simulated, no real money) options trading strategy against a brokerage API. It is not a public product, is not distributed to anyone else, and has exactly one user: its developer.

What it uses the Gmail API for

The application requests one Gmail scope, gmail.send, for exactly one purpose: to email the developer's own inbox a plain-text alert when the trading bot hits a situation it cannot resolve automatically — for example, when a simulated options contract expires in-the-money and the bot has no logic to detect or unwind the resulting position, so the developer needs to check it by hand. The application never reads, searches, modifies, or deletes anything in any mailbox, and it only ever sends mail to its own developer.
