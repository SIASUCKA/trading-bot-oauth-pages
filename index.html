This is a personal, single-user automated trading bot that manages my own paper-trading (simulated, no real money) options positions on Charles Schwab. It uses the Gmail API, with the gmail.send scope only, to email a single alert address (my own) when a position requires manual review — for example, when an option leg expires in-the-money and the bot has no logic to handle the resulting stock position automatically.

This application is not distributed to the public and is not intended for use by anyone other than its developer.
