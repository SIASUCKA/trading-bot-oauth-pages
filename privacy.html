This application requests the gmail.send OAuth scope for one purpose only: to send outbound alert emails from my own Gmail account to myself when my personal trading bot needs manual attention.

What this application does

  • Sends plain-text email notifications to a single, fixed recipient address (the developer's own email address).

What this application does NOT do

  • It does not read, search, modify, or delete any email in any mailbox.
  • It does not access, store, or transmit any Gmail message content belonging to any user other than the developer.
  • It does not share any data with third parties.
  • It does not use any data for advertising or analytics.

Data retention

No Gmail data is retained. The application holds only an OAuth refresh token, stored locally on the developer's own private infrastructure, used solely to authenticate outbound send requests.

This application is for personal, single-user use only and is not available to the public.
